# Technology Stack

## Backend
- **Framework**: Express (Node.js)
- **Database**: PostgreSQL (via Prisma ORM)
- **Key Dependencies**: bcryptjs, cors, multer, node-cron, qrcode, whatsapp-web.js, xlsx
- **Architecture Type**: Service/API-centric

## Frontend
- **Framework**: React.js (via Vite)
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Key Dependencies**: lucide-react, jspdf, xlsx, tailwind-merge
- **Architecture Type**: Component-based SPA
